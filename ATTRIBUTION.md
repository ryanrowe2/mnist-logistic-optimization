# Attribution and research provenance

**Academic project author:** Ryan Rowe. **Institution:** University of California, San Diego. **Course:** MATH 173A, numerical optimization, with original coursework from 2023 and the MNIST report dated July 18, 2024.

**Historical source evidence:** `docs/sources/2024-original-report.pdf` is the original 16-page report, included to preserve methods and printed historical evidence. `MATH 173A HW 3.pdf` and `MATH 173A HW 4.pdf` were inspected from the author's file library as supporting sources and are **not** included in the public package because they contain additional unrelated course content and are much larger. Standalone original executable source code was not recovered; all `src/` code is reconstructed or newly authored in the present engineering rebuild.

**New work:** The modern Python package layout; stable mathematical computations; corrected optimization-direction implementations; deterministic data construction; official-split protocol; tests, CLI, figures, CI, and documentation were prepared in this portfolio rebuild. The original source report's mathematical/experimental limitations are not retroactively rewritten or concealed.

**Dataset:** MNIST handwritten-digit database, creators Yann LeCun, Corinna Cortes, and Christopher J. C. Burges, as credited by [OpenML data 554](https://www.openml.org/search?id=554&type=data). Code fetches public data through OpenML; the dataset is not redistributed in this repository. Dataset license/redistribution questions should be checked against the rights holder's terms prior to any bundling.

**License:** The repository's newly created code is proposed for MIT licensing, subject to the author's publication approval. This is not a license grant for third-party MNIST data, original course materials, or their embedded figures.
